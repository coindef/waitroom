# README promo assets

Pixel-art stills for the repository README. Promo art only.

The README top uses the pixel lockup in
[`docs/brand/`](../../docs/brand/) (`readme-lockup-light.png` /
`readme-lockup-dark.png`). Do not point the README at a terminal-blob
lockup. `readme-logo-pixel.svg` stays in this folder as a labeled stand-in
and is not the image at the top.

Style direction for these stills: cartoon pixel, navy starfield, cyan and
gold. That palette is for this promo art. It is not a new product brand.

The Blind-wait poster is a **temporary style reference**, not a hero, not a
wager, and not final Design work. Drop it at
`ads/assets/readme-hero-pixel-ref.jpg` if it should live in the tree. The
README does not use it as the demo.
